# 💻 Exercícios de C#

Repositório onde guardo os exercícios de **C# e .NET** que resolvo durante meus estudos. Cada exercício fica em sua própria pasta, com o código-fonte e uma breve descrição do problema.

O objetivo é registrar minha evolução, praticar os fundamentos da linguagem e ter um material de consulta para revisões futuras.

---

## 📚 Conteúdos praticados

- **Fundamentos da linguagem:** variáveis, tipos, operadores, condicionais e laços
- **Anatomia de classes:** campos, propriedades, construtores e métodos
- **Os quatro pilares da POO:** encapsulamento, herança, polimorfismo e abstração
- **Namespaces:** organização do código em contêineres lógicos
- **Arquitetura em camadas:** separação em `Entities`, `Services` e `Repositories`

> A lista cresce conforme novos exercícios são adicionados.

## 📁 Estrutura do repositório

---

## ▶️ Como executar

**Pré-requisito:** [.NET SDK](https://dotnet.microsoft.com/download) instalado.

```bash
# Clone o repositório
git clone https://github.com/SEU-USUARIO/exercicios-csharp.git

# Entre na pasta do exercício desejado
cd exercicios-csharp/01-NomeDoExercicio

# Execute
dotnet run
```
